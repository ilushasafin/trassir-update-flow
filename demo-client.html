Демо: окно обновления

Что поменялось в окне обновления после встречи с Егором. Шаги идут по порядку показа: каждая ссылка открывает окно сразу в нужном состоянии. Под шагом — какой комментарий он закрывает. Слева в прототипе можно открыть всю раскадровку.

Обновление по сети

  1. Пришло обновлениеПодарочек на кнопке «Обновление ПО» и у «vms» в дереве. Жёлтой подсветки больше нет.Если показываем подарок в дереве — на кнопке тоже иконку.
    Открыть →
  2. Окно «Обновление по сети»«Что изменилось в 4.9.15.0» свёрнуто — раскрывается по клику. Галочки автопоиска здесь больше нет.«Что изменилось» — разворачивающимся списком; галочку лучше отсюда вынести.
    Открыть →
  3. Загрузка в фонеОкно закрылось, ход загрузки — строкой под кнопками и у «vms» в дереве.Лоудер нравится; мегабайты покажем, минуты — обсудим с разработкой.
    Открыть →
  4. «Перезапустить и установить»Можно отложить («Позже») или удалить загруженное.Сделать кнопку «Удалить это обновление».
    Открыть →
  5. Установка позжеЗагруженное ждёт в строке под кнопками: «Перезапустить и установить» или «Удалить».Загрузить днём, а установить вечером, когда операторы ушли.
    Открыть →
  6. Пока ждали — вышла версия новееОкно предлагает удалить загруженную 4.9.15.0 и загрузить 4.9.16.0.Написать, что вышла новая версия: можно загрузить её, а старую удалить.
    Открыть →

Автопоиск обновлений

  1. Настройка в разделе «Сеть»Раздел по реальному интерфейсу, галочка «Автоматически искать обновления ПО» — под «Шифрованием портов».В настройках сети эту галочку добавить.
    Открыть →
  2. Автопоиск выключен — окно «по сети»Вместо обновления — «Автоматический поиск выключен» и кнопки «Включить» (сразу ищет) или «Обновить из файла».Нажимаю «Включить» — он включается и начинается поиск.
    Открыть →
  3. Автопоиск выключен — список измененийТа же просьба включить поиск.Здесь тоже, если выключен, — просьба включить.
    Открыть →

Обновление из файла

  1. Поиск файловПока ищем — «Если поиск идёт долго, выберите файл вручную» и «Обзор…».Если файл долго ищется — выбрать вручную, и тогда уже «Обзор».
    Открыть →
  2. Файл выбран вручнуюВ списке только выбранный файл. Галочки автопоиска нет.Если выбрал вручную — тут будет один файл.
    Открыть →
  3. Ничего не нашлосьАдрес сайта — видимым текстом, чтобы набрать с телефона.Ссылку текстом поставить, чтобы мог ввести сам.
    Открыть →

Справка

  1. Список изменений«Доступна» — только у последней версии, у промежуточных отметок нет.«Доступна» писать только для последней.
    Открыть →
  2. Журнал обновленийВесь список сразу, без отката и без «Сохранить для техподдержки».Возвращение пока уберём; список — сразу весь; лишнее урезать.
    Открыть →

«Осталось ~N мин» при загрузке и полоса при передаче файла на сервер — вопросы к разработке. Номера версий, размеры и записи журнала условные.

Демо: страница загрузок

Что поменялось на сайте после встречи с Егором. Шаги идут по порядку показа: каждая ссылка открывает сайт сразу в нужном состоянии. Под шагом — какой комментарий он закрывает.

Страница

  1. Страница целикомБез синей подложки, в стиле сайта. «ПО TRASSIR», «Мобильный клиент», «Драйверы», «Утилиты» — заголовки одного уровня, «Другие программы» убрали.Убрать синий фон, сделать в едином стиле; заголовки должны быть равнозначны.
    Открыть →

Подбор по номеру сборки

  1. Одно обновление — сухая выдачаТолько файлы: имя, версия, дата, размер. Имя — ссылка (копируется правой кнопкой), рядом «Копировать ссылку» и «Скачать». Сервер и клиент — одним списком, без вкладок. Подсказка ⓘ у поля — где посмотреть номер сборки.Максимально упростить выдачу; без разделения на сервер и клиент; кнопка «Копировать ссылку».
    Открыть →
  2. Обновление в 3 шагаШаги по порядку, на каждом — файлы. Без плюсов и минусов и второй колонки «Установить заново» — она стала одной строкой.Убрать «можно удалённо», «ехать не нужно» и прочие пояснения.
    Открыть →
  3. Серийный номер — только когда нуженСборка стояла на нескольких моделях: поле серийного номера появляется в результате, с объяснением зачем и подсказкой, где его найти. В форме поиска поля больше нет.Серийный номер появляется, только когда это необходимо, и где его посмотреть.

# Обновление ПО TRASSIR — прототипы

- `index.html` — стартовая страница со ссылками на прототипы.
- `site.html` — новая страница загрузок на dssl.ru. Самодостаточный файл, правится напрямую. Переключатель «Сценарии» внизу слева; `?res=chain` и другие параметры сразу открывают нужный вариант подбора.
- `client.html` — окно обновления ПО в клиенте. Собирается из `src/`, вручную не правится:

  ```bash
  python3 update-flow/src/build.py
  ```

  Базовые стили и значки сборка берёт из соседнего прототипа `device-settings-dialog/src/template.html`, поэтому собирать нужно в рабочей папке TRASSIR, где лежат оба прототипа.

Номера сборок, правила подбора, пути к настройкам и часть текстов условные.
